# SheepShaver SCSI Bridge Driver

**Status:** Planning
**Branch:** `os9-minimal`
**Milestone:** TBD

## Overview

A Mac OS device driver installed in the SheepShaver unit table that provides SCSI I/O to PPC applications, bypassing the broken Mixed Mode dispatch path.
